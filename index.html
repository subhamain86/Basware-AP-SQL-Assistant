Welcome — what does this tool do?

AP-SQL Assistant · Version 11.3 — writes database queries for you — both read-only reports and Change Request SQL — using your organization's approved schema as its single source of truth. New in V11.3: a compact, centered layout across every page, scrollable panels for long table/column/filter lists so the page itself stays short, and a fix for the Update Schema password gate (a "Forgot password? Reset to default" recovery link is now on the locked screen).
