Welcome — what does this tool do?

This assistant writes database queries for you — both read-only reports and Change Request SQL — using your organization's approved database schema(s) as its single source of truth. Version 11.9 refines the Query Builder layout into a compact, professional structure: Describe What You Need and Generated SQL side by side, followed by a single Manual Selectors card with Tables & Columns, Advanced Options, and Selected/Described Requirements tabs — all existing V11.8 functionality (AI SQL generation, self-review, Error Rectifier, CASE/DECODE, filters, schema management, and security) is fully preserved underneath.

GitHub-Hosted Schema Sync (Administrator) Option B

Connect with your repository details and a Personal Access Token. This connection can be saved to an encrypted vault below, so any authorized user can restore it on any machine without re-typing the token.

Your Personal Access Token is stored only in this browser's local storage and sent only to api.github.com over HTTPS. Use a fine-grained token scoped only to this one repository with Contents: Read and write permission.

Secure GitHub Connection Vault Since V10.7

Encrypt the GitHub connection above (owner, repository, branch, path, and token) with a passphrase, and publish it to the project repository as an encrypted vault file, so any authorized user on any machine can unlock the exact same connection just by knowing the passphrase — without ever seeing or re-typing the token.

This is a browser-only application with no server. The vault is genuinely encrypted (AES-256-GCM), and the token is never stored or shown in plain text anywhere — but because there is no server-side secret store, the passphrase itself (never stored alongside the vault) is the real access boundary and must be shared with authorized users separately, exactly like the operational password below.
