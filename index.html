Welcome — what does this tool do?

This assistant writes database queries for you — both read-only reports and Change Request SQL — using your organization's approved database schema(s) as its single source of truth. Version 11.8.2 adds an interactive Guided Walkthrough and a navbar stability fix; every V11.8.1 Query Builder layout and engine (AI SQL generation, self-review, Error Rectifier, CASE/DECODE, schema management, security) is fully preserved.
