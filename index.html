Welcome — what does this tool do?

AP-SQL Assistant · Version 11.3.1 — writes database queries for you — both read-only reports and Change Request SQL — using your organization's approved schema as its single source of truth. New in V11.3.1: a hardened navbar that always fits the screen at any width, and a fully rebuilt Update Schema password-authentication flow using a single, centralized, salted-hash mechanism shared by every protected action in the app.
